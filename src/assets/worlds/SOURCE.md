# World screenshots

Real captures of the CINEPOL server, copied from the website repository
(`cinepol-web/src/assets/world/`) and converted to WebP at 1280px wide.

| File | World | Subject | Color temperature |
| --- | --- | --- | --- |
| `cinepol-recursos.webp` | Overworld | Resource world | 5600 K |
| `cinepol-parcelas.webp` | Overworld | Policarpier village | 5600 K |
| `cinepol-nether.webp` | Nether | Nether hub | 2000 K |
| `cinepol-end.webp` | End | End hub | 7500 K |

Rules (from the website): 16:9 captures, no Minecraft UI (no hotbar, hearts,
chat or F3 screen), never type set directly on a bare screenshot.
These images are CINEPOL brand assets and are not covered by the GPL.
